# Python libraries the IN-PROCESS attack modules import. The egress/segmentation
# modules are pure stdlib and need NONE of these; the other modules shell out to
# CLI tools (impacket-scripts, hydra, snmp, ...) installed by bootstrap.py via apt.
# So you only need these if you run the in-process AD modules (dcsync/psexec/
# wmiexec/nopac/samaccountname_spoof) or kerberos_asrep.
#
#   python3 -m pip install -r requirements.txt        # (bootstrap.py does this for missing ones)
#   python3 preflight.py                               # verifies they actually import
#
# cryptography is listed explicitly because a stale/shadowed one breaks
# dns.asyncquery -> cryptography.hazmat.asn1, which is what makes noPac /
# sAMAccountName NO-RESULT. preflight imports that exact chain to catch it.
#
# pycryptodome provides Crypto.Hash.MD4 — ldap3's NTLM bind (used by noPac /
# sAMAccountName via the vendored helper) needs MD4 for the NT hash, and MODERN
# OpenSSL (3.x, e.g. current Kali/Debian) DISABLES md4 in hashlib, so without
# pycryptodome the bind dies with "unsupported hash type MD4" -> NO-RESULT.
